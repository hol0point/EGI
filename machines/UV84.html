UV84

Start of Every Day

  1. Turn on Heater
  2. Once heated click on maintenance in the control software
  3. Hold each purge button on the machine for 5 seconds (1)
  4. Apply adhesion promotor to material
  5. Move the carriage over the material using Ctrl-Arrow Keys and triangulate the position using the markers
  6. Click on the Lifter Control button and click on auto detect and pick No
  7. If you followed all the steps you should be ready to move on to ColorByte rip

ColorByte Rip Software

  1. Place signs to be printed at 0,0
  2. Make surrounding plate size slightly larger than size of the printer area
  3. Make sure all colors and primers are applied
  4. Select only the items to print.
  5. Click File/Send to rip and click ok
  6. Go to the rip software(green one) look at preview to make sure it looks ok
